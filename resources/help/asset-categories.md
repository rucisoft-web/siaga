# Kategori aset
Pengelompokan aset (AC, TV, furniture, linen, dll.) beserta default kritikalitas, mode pelacakan, dan interval PM.

![Kategori aset](img/asset-categories.png)
*Daftar kategori.*

- **Pelacakan**: *individual* (per unit berlabel) atau *quantity* (per jumlah).
- **Kritikalitas default**: dipakai saat aset baru dibuat; menentukan prioritas pekerjaan.
- **Interval PM usulan**: jadwal perawatan preventif default.
