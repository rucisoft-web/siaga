# Riwayat cetak label
Setiap PDF/halaman cetak label tercatat sebagai batch: nomor, operator, media, jumlah label, tujuan (baru/cetak ulang), dan status.

![Riwayat cetak label](img/label-print-batches.png)
*Daftar batch cetak.*

## Status batch
- **PDF siap**: dibuat, belum diunduh.
- **Sudah diunduh**: PDF/halaman cetak sudah dibuka.
- **Cetak dikonfirmasi**: operator memastikan label benar-benar tercetak.
- **Dibatalkan**.

## Tindakan
- **Cetak label**: membuka PDF lagi.
- **Konfirmasi sudah dicetak**.
- **Konfirmasi pemasangan**: membuka layar pemasangan untuk label batch ini.

Batch dari layar Pendataan ditandai sebagai cetak lapangan dan hanya bisa dibuka oleh petugas pembuatnya atau pengguna dengan hak cetak label.
