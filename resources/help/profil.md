# Akun saya
Mengubah nama, kata sandi, dan verifikasi dua langkah (MFA) akun Anda.

![Layar profil](img/profil.png)
*Layar Akun saya.*

## Langkah
1. **Kata sandi**: isi kata sandi lama, lalu kata sandi baru dua kali. Minimal 8 karakter, campur huruf dan angka.
2. **Verifikasi dua langkah**: ketuk aktifkan, pindai kode yang muncul dengan aplikasi authenticator (Google Authenticator, Microsoft Authenticator), lalu masukkan 6 digit kodenya. Simpan kode pemulihan di tempat aman.
3. Tekan **Simpan**.

## Catatan
- Akun baru wajib mengganti kata sandi saat login pertama; sebelum diganti, layar lain tidak bisa dibuka.
- Lupa kata sandi: minta Admin IT melakukan **Reset sandi** di menu Pengguna.
