# Laporan
Laporan siap unduh untuk manajemen dan audit.

![Laporan](img/laporan.png)
*Pilih jenis laporan dan periode, lalu ekspor.*

| Laporan | Isi |
|---|---|
| Backlog work order | Pekerjaan terbuka per status, umur, prioritas |
| Kepatuhan SLA laporan | Respons dan pemulihan dibanding target |
| Work order selesai & MTTR | Waktu rata-rata perbaikan |
| Register aset | Seluruh aset dengan lokasi, kondisi, status |
| Status label per lokasi | Label tercetak, terpasang, belum terpasang per lokasi; berguna memantau pendataan |
| Biaya pemeliharaan | Biaya per work order, aset, kategori, periode |

Unduh sebagai CSV, bisa dibuka di Excel untuk diolah lebih lanjut.
